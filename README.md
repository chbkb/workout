# Körperkraft Training

Persönliche Trainings-Web-App ohne Sprünge: Workouts mit Timer und deutscher Sprachansage, mehrwöchige Trainingspläne, Fortschritt und ein Katalog mit 53 Übungen samt YouTube-Videos.

- `index.html` ist die fertige App (eine Datei, keine Abhängigkeiten außer Google Fonts).
- `src/` enthält die Vorlage und die Daten (`uebungskatalog.json`, `workouts.json`), aus denen `index.html` gebaut wird.
- Alle Trainingsdaten bleiben im Browser des Geräts (localStorage).
- Videos werden über den YouTube-Player eingebettet (youtube-nocookie.com), nicht heruntergeladen.
